
Lexical Structure/Grammar

Source text is just a sequence of characters
For the interpreter to understand it, the string has to be parsed to a more
structured representation.

Lexical analysis: initial step of parsing
text gets scanned from left to right and
converted into a sequence of individual, atomic input elements.

White spaces and comments are stripped
identifiers, keywords, literals, and punctuators (mostly operators), will be
used for further syntax analysis.

Line terminators and multiline comments are also syntactically insignificant,
but they guide the process for automatic semicolon insertion to make certain
invalid token sequences become valid

line terminator characters are used to improve the readability of the source
text

line terminators can also influence the execution of JavaScript code
Line terminators also affect the process of automatic semicolon insertion

White space and line terminators are often conflated
String.prototype.trim() removes all white space and line terminators
